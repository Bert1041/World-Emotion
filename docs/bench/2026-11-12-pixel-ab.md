# Pixel 6 Pro A/B, 2026-11-12 (bridge PR B, U2 weather)

Builds were run in turns on the same phone (production build over `adb reverse`, Chrome via CDP),
so heat drift hits both sides of each pair alike. Gate matrix, one repeat per round.

| Label | Build |
|---|---|
| `main`, `main2`, `main3` | `main` at 350002c (Phase 5.5a): square particles |
| `prb` | PR B at 1c440b9: a pre-rendered glow sprite, `drawImage` per particle |
| `fix` | batched circles: a faint halo path and a core path per soft mood |
| `fix2` (`-warm`, partial) | `fix` with square cores: tried, no gain, reverted |

Cool runs (battery 31–33 °C at start; thermal status 0, reaching 1 in the `main2`/`fix` set).
`-warm` files ran with `--allow-warm` at 36–37 °C and are not comparable to the rest.

## Drag at 60 Hz, 4x CPU, script p95 (ms) and weather layer (`fx`, ms)

| Round | main | prb (sprites) | main2 | fix (circles) |
|---|---|---|---|---|
| 1 | 15.1 · fx 0.6 | 17.7 · fx 2.2 | 16.2 · fx 0.7 | 17.4 · fx 1.1 |
| 2 | 16.3 · fx 0.6 | 19.0 · fx 2.4 | 17.3 · fx 0.7 | 18.0 · fx 1.2 |
| 3 | 15.2 · fx 0.7 | 19.2 · fx 2.3 | 15.6 · fx 0.7 | 17.4 · fx 1.1 |
| dropped frames | 0–0.7 % | 6.8–10.1 % | 0–2.2 % | 2.2–3.3 % |

- Sprites: about +20 % against `main`. Fails the bridge's "within 10 %".
- Circles: +7 %, +4 %, +11.5 % against the `main` run next to each; +7.6 % on average.
- Square cores (`fix2`, one warm round): `fx` 1.2 ms, no better than circles. The cost is the
  halos. Reverted.
- Without CPU throttling every build is level with `main` or slightly faster (less map work).

What shipped after this run: circles, plus halos faded out while a finger drags the globe (they
cost most there and are seen least). **That build has not been benched on the Pixel yet.**
